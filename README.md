# Chat-Box
Chat Box
A small, static chat UI built with HTML and CSS.

Features

Simple UI: Clean chat interface with left/right message bubbles.
Responsive: Uses viewport meta and modern fonts for good display.
No build: Plain static files — open in a browser.
Files

UI: interface.html — main HTML.
Styles: interface.css — stylesheet.
How to run

Open in your browser: run open interface.html (macOS) or double-click the file.
Or serve locally:

python3 -m http.server 8000# then visit http://localhost:8000/interface.html
Development

Edit interface.html and interface.css to modify layout, colors, or content.
Fonts are loaded from Google Fonts (Inter).
